Unreal Engine 5 Editor Utility Widget Adaptive AI

Adaptive Combat Tool

Real-time player intent classification → dynamic boss behaviour

An adaptive boss combat system built as an Unreal Engine 5 Editor Utility Widget. It reads the player's attacks, dodges, distance, and health, classifies their intent — Aggressive, Defensive, Panic, or Balanced — and switches the boss between four modes: Normal, Counter, Chase Aggressive, and Heavy Pressure. It runs in Adaptive mode or Fixed Rules mode, and includes an editor tool so designers can configure encounters without touching gameplay code.

Intent Classification
Classifies the player as Aggressive, Defensive, Panic, or Balanced from attacks, dodges, distance, and health.
Boss Modes
Normal, Counter, Chase Aggressive, and Heavy Pressure, run in Adaptive mode or Fixed Rules mode.
Intent Tuning
Adjustable attack/dodge score gain, decay rate, classification interval, and panic/balance thresholds.
Combat Configuration
Per-mode tuning of attack cooldown, attack/stop range, movement speed, and damage.
Designer Tooling
Configure encounters in the editor without touching gameplay code, with auto-setup and validation tools.
Combat Systems
Light/heavy combos, directional dodge, weapon hit detection, AI chase/attack, and animation-driven combat.
